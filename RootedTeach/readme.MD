## ✨ A. What is RootedTeach
* RootedTeach is a next-generation Learning Management System (LMS) that seamlessly integrates programming assignment management with advanced AI detection. 
* Teachers can efficiently manage classes while students submit their work, allowing the system to scientifically analyze code for both human-authored logic and AI-generated patterns.

## 🔥 B. Getting Started

1. First, run the terminal and cd to `Front-End` directory.
2. Start front-end.
```
npm start
```
3. Now, run the second terminal and cd to `Back-End`.
4. Then start back end server.
```
node server.js
```
5. Finally, run the third terminal and cd to `ML`.
6. Start ML server.
```
node mlServer.js
```
