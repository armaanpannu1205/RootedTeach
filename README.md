## How to Log In

1. First, run the terminal and go to `Front-End` directory.
2. Start front-end.
```
npm start
```
3. Now, run the second terminal and go to `Back-End`.
4. Then start back end server.
```
node server.js
```
5. Now you can see the log-in page.
6. Enter test email and password.

|         | Student | Teacher |
|---------|--------|---------|
| Email | `student@test.com`| `teacher@test.com` |
| Password | `student` | `teacher` |
